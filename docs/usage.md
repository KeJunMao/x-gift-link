# 使用指南

[返回 README](../README.md)

## 安装与更新

在 Chrome 或 Edge 的扩展管理页启用开发者模式，加载包含 `manifest.json` 的目录。安装包需要先解压。

更新时，将新版本解压到原来的扩展目录，再到扩展管理页点击「重新加载」。保留同一扩展及其目录，便于继续使用已有设置和订单记录。

扩展面向普通浏览器窗口；账号操作需要同一浏览器中的 X 登录状态。首次使用可点击弹窗右上角「登录」打开 X。

## 从账号到链接

输入收礼人的用户名，支持带或不带 `@`。点击「检查」后，扩展检查赠礼资格，并自动读取可用时长的报价。选定时长、点击「继续」后可以核对报价并创建链接。

创建前会再次检查账号、报价和网络。报价变化时，扩展返回时长选择，让你确认新价格。成功后可复制链接或直接打开付款页。

关闭弹窗后，后台任务会继续；重新打开可查看当前进度。浏览器或后台任务中断时，重新打开后按提示继续。

## 配置代理

弹窗顶部的「代理」提供两种模式：

| 模式 | 用途 |
| --- | --- |
| 浏览器 | 沿用浏览器原有网络设置 |
| 自定义 | 为 `x.com` 指定 HTTP、HTTPS 或无认证 SOCKS5 代理 |

HTTP / HTTPS 支持用户名和密码。VLESS、AnyTLS 等协议可先通过本地代理客户端转换为 HTTP 或 SOCKS5，再填入本地地址与端口。

填写后点击「测试」可查看连接状态、X 出口国家和耗时。测试期间会临时应用候选代理，并影响同一普通浏览器配置中的 X 请求；结束后恢复原设置。点击「保存」才会持续启用配置。

**自定义代理接管普通浏览器配置的代理设置：`x.com` 走指定代理，其他域名直连。** 这会影响同一配置下的其他标签页；打开 Stripe 付款页时也使用直连。切回「浏览器」并保存，可释放控制并恢复原网络设置。

代理密码仅存于当前浏览器会话，退出浏览器后需要重新填写。更换代理后重新检查账号，获取当前出口下的报价。

「X 出口」展示 X 页面返回的国家信息；未返回时显示「未知」。可点击刷新按钮重新读取。

## 已有链接与重新生成

同一收礼人和套餐已有记录时，扩展会复用已创建的链接。它不会自动检查链接是否已付款或过期，需要你打开付款页核对。

如果创建结果不明，扩展保留原记录并阻止自动重试。请先检查 X 页面及已有订单，再点击「核对后重新生成」。这会将原记录归档，允许你重新选择套餐；原链接仍可能有效。

## 常见问题

### 提示登录或请求被拒绝

在同一浏览器中打开 X，检查登录状态并完成页面要求的验证，再重试。保持一个普通窗口的 X 页面打开。

### 账号无法接受礼品

赠礼资格由 X 决定。核对用户名，或换一个符合赠礼条件的账号。

### 报价获取失败，或只显示一种时长

检查网络，点击「刷新报价」重试。扩展只展示成功读取的套餐，不可用的时长不会提供固定参考价。

### 出口国家显示「未知」

先打开 X 页面并刷新出口信息。网络可用但 X 未提供国家信息时，也会显示「未知」。

### 自定义代理无法启用

检查地址、端口和凭据，确认本地代理客户端正在运行。其他代理扩展或浏览器策略可能正在控制代理设置，需要先处理冲突。

### 浏览器重启后代理认证失败

重新输入代理密码并保存，然后重新检查账号。

### 想清除本地记录

卸载扩展会清除它的本地存储。清除前先核对并妥善保存未完成的订单，避免丢失记录后重复创建。
