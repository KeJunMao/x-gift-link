# 隐私与权限

[返回 README](../README.md)

X Gift Link 在浏览器内运行，没有项目方后端、遥测或分析服务。账号检查、报价和链接创建直接请求 `x.com`；点击「打开」后，浏览器跳转到 X 返回的 Stripe 付款页。

## 数据如何使用

| 数据 | 用途与存储 |
| --- | --- |
| X 登录 Cookie | 检查当前登录状态，读取 CSRF Cookie 并利用 X 页面会话发送请求；扩展不持久化 Cookie 值 |
| 收礼人账号、报价、当前步骤 | 保存于扩展本地存储，用于恢复操作 |
| 订单与付款链接 | 保存于扩展本地存储，用于复用链接、阻止重复创建；归档历史最多保留 100 条 |
| 代理地址、端口、用户名 | 保存于扩展本地存储 |
| 代理密码 | 保存在浏览器会话存储，退出浏览器后清除 |
| 出口国家与代理测试结果 | 保存于扩展本地存储，用于显示网络状态 |

测试代理时，还会临时保存原代理设置供恢复，并将测试凭据放入会话存储；恢复后删除临时配置。扩展本地存储仅向可信扩展上下文开放。

扩展不收集银行卡资料，也不提交付款确认。复制链接时，仅将你选择的链接写入剪贴板。

## 为什么需要这些权限

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存步骤、报价、订单与代理配置 |
| `cookies` | 检查 X 登录状态并读取请求所需的 CSRF Cookie |
| `scripting` | 在 X 页面中发起账号、报价、赠礼及网络信息请求 |
| `proxy` | 应用和恢复用户选择的代理设置 |
| `webRequest`、`webRequestAuthProvider` | 处理自定义 HTTP / HTTPS 代理认证及请求结束事件 |
| `alarms` | 在代理测试中断后触发恢复检查 |
| `https://x.com/*` | 将网站访问权限限制到 X |

自定义代理的作用范围是普通浏览器配置，其他域名会直连。具体用法见[代理说明](usage.md#配置代理)。

## 清除与反馈

卸载扩展会删除扩展本地数据。卸载前请核对未完成订单。

反馈问题时，请隐藏 Cookie、代理密码、真实付款链接和个人信息。安全问题的反馈方式见[安全说明](../SECURITY.md)。
